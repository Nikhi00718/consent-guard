# Critique: project page (docs/index.html) — 2026-09-20

Method: two independent reviewers, run in isolation from each other and from the author — A, a design review of the live page; B, deterministic measurement. The design skill's bundled binary detector did **not** run (not on disk; downloading and executing it was refused), so B substituted axe-core 4.13, headless Chromium instrumentation, computed contrast, and a source grep. A partial run of the skill's critique process, recorded as such.

Target: https://nikhi00718.github.io/consent-guard/ at the commit that published the first rebuild.

## Verdict

Authored for this product above the fold and in the scorecard; category-interchangeable below it. The drag seam, the self-redacting headline, and a published table of failure rates are things no competitor can paste a logo onto. The header, the reassurance row, the three-column admissions and the install layout are generic. The reviewers agreed the authored parts were the ones the build broke.

## Findings and what was done

| Sev | Finding | Source | Action |
|-----|---------|--------|--------|
| Blocking | Every image vertically stretched: `img` had `max-width` but no `height: auto`, so the HTML `height` attribute applied as CSS. App screenshots rendered at ~28% of their proper width; the hero photo was a smear on phones | A and B agreed | `img { height: auto }`; assets re-cut; verified zero distortion at 1440, 768 and 390 |
| Major | The invisible range input covered the figcaption: clicking the disclaimer jumped the photo, and the text could not be selected or copied. Also the cause of axe's one `color-contrast` incomplete | B only | Control scoped to a `.plate` wrapper around the photo; caption sits outside it. Hit-test and double-click selection verified; axe incomplete gone |
| Major | Scorecard bars encoded pixel coverage while the number beside them was region catch rate, so the bar always flattered — in the section whose claim is that it does not flatter | A only | Bar and number are now the same measurement; area coverage moved to the line under each row; key moved above the rows; rows sorted worst first |
| Major | Install commands clipped ~25% with no copy control, on the page's conversion step | A and B agreed | Commands wrap; a copy button per block with a copied state; clipboard verified |
| Major | Arrow keys moved the seam 0.1% — about 1000 presses to cross | A and B agreed | `step="1"`, plus `aria-valuetext` announcing the position |
| Minor | `figure` kept its 40px user-agent margin, so the signature element was the only block off the grid | A only | `figure { margin: 0 }` |
| Minor | The seam bled 45px past the photo, through the caption | A only | Seam bounded to the photo; verified seam bottom equals plate bottom |
| Minor | Monospace on prose labels ("the photo as it was"), breaking DESIGN.md's own mono rule and its label spec | A and B agreed | Labels set in Archivo condensed caps; mono now only on keys, percentages, paths and commands |
| Minor | Section numbers set in mono as standalone kickers | A and B agreed | Kept (a real four-step sequence) but set in Archivo, inline with the heading |
| Minor | Dead tokens (`--shadow-print`, `--marker-soft`, `--marker-press`) and colour literals outside the token set | B only | Literals tokenised (`--ink`, `--loupe`, `--select`); `--marker-press` wired to the button's pressed state; unused tokens dropped |
| Minor | Reduced motion did not cover the strip's scroll-snap settle | B only | `scroll-snap-type: none` under reduced motion |
| Minor | A `pre` was a keyboard tab stop with nothing to scroll | B only | Commands wrap, so no `pre` needs a tab stop; removed |
| Minor | Mobile nav hid the two links that sell the product | A only | Hides the GitHub link instead; the other three stay |
| Minor | Caption's left/right labels collapsed to the same edge on phones, destroying the spatial mapping | A only | Caption is a grid; labels hold their ends, the note wraps below |
| Minor | No closing action on a 4,888px page; hero offered the release while the install section said clone, unreconciled | A only | Closing action repeated at the end of the run section; the two paths named as the same code |
| Minor | `-ExecutionPolicy Bypass` shown to non-technical readers with no explanation | A only | One plain line saying what it does and that both scripts can be read first |
| Minor | The hero image shows an uncovered barcode under a claim that codes get covered | A only | Caption states the stripes are drawn, not a real barcode, so there was nothing to decode |
| Minor | Repository description still described a research dataset project, contradicting the page one click away | A only | Description rewritten to match the product |

Not acted on: A's question of whether the contact sheet is the refused alternating-rows pattern rotated 90°. The sheet stays, with frames re-cut to details rather than whole windows so each one is legible. Worth revisiting if the page gets another pass.

## Evidence after the fixes

- axe-core: 0 violations and 0 incompletes at 1440, 768 and 390.
- Horizontal overflow: 0 at every width tested, including 320 and at 200% text.
- Image distortion: none at any width.
- Drag: mouse 18%, click-to-jump 82%, synthesized touch 13%, keyboard 3 presses = 3%, no horizontal page scroll during touch.
- Contrast (measured before the change, palette unchanged): lowest text pair 5.29:1; everything else 6.7:1 to 15.6:1.
- Weight: ~325 KB over 8 requests, one origin, zero third-party requests, font loaded once.
- Page height on a phone dropped from 5,872px to 5,218px.
